# DADOS TOTALMENTE FICTICIOS

Os arquivos deste diretorio foram criados exclusivamente para testes. Nenhuma linha representa uma pessoa, conta ou transacao real.

Casos deliberados:

- duplicidade em PicPay;
- sinal Unicode de debito;
- ID zero e IDs de tamanhos diferentes;
- historico Bradesco contendo ponto e virgula;
- transacao em PDF iniciada por texto.
